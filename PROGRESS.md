## Границы подтверждения

Тесты выполнялись через TestClient внутри тестового процесса. Это не доказательство запуска отдельного сервера, ручного сценария или установки в чистое окружение. Код написан пользователем с подробными объяснениями и подсказками; успешные проверки не равнозначны независимому освоению материала.

Хранение пока только в памяти одного процесса. Генерация ID через `len(products) + 1` — учебное упрощение для последовательного добавления без удаления, не конкурентно-безопасное решение.

Этапы 2–7 пока являются планом. Коммиты и push ассистентом не выполнялись; наличие файлов на диске не означает, что последние изменения сохранены в Git или отправлены в удалённый репозиторий.
